## Коворкинг

На главной — горизонтальная лента карточек студии и диалог заявки.
Время показывается в часовом поясе Новосибирска. Допустимы 1–20 участников,
продолжительность от 30 минут до 8 часов, начало в будущем в пределах 90 дней.
Это заявка на рассмотрение, а не автоматическая гарантия свободного места;
совместимость пересекающихся заявок проверяет сотрудник при подтверждении.

Участник видит свои заявки, статус и ответ студии, может отменить активную заявку.
В админке: раздел «Коворкинг», фильтры, постраничный список, подтверждение/отклонение,
отмена и комментарий участнику. Изменения записываются в аудит.

API (префикс /api/v1):

- GET /coworking/bookings/me — свои последние 50 заявок;
- POST /coworking/bookings — новая заявка, обязательны авторизация, CSRF и Idempotency-Key;
- PATCH /coworking/bookings/:id/cancel — отмена собственной заявки;
- GET /admin/coworking/bookings — административный список, status/limit/offset;
- PATCH /admin/coworking/bookings/:id — status и adminNote, только администратор с CSRF.

Перед обновлением API применить миграцию 0021_coworking_bookings стандартной командой
db:migrate от владельца БД. Она только добавляет таблицу, индексы и права runtime-пользователя;
существующие балансы, мероприятия, заказы и привязки не меняются.
Для отката приложения таблицу с накопленными заявками оставить.
